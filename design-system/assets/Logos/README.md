# Logos

Twenty-six SVGs: the mark (the bird), the wordmark, the complete lockup and the Hope
Channel co-brand. All vector, in the approved colors — none uses `currentColor`.

## How to choose

| Prefix | When to use it |
|---|---|
| `mark-` | The symbol alone. Avatar, favicon, small application, or when the wordmark already appears in context. |
| `wordmark-` | The type alone. The `orange` variants set "THE EARTH" in `fire-orange` — the preferred form when there is room. |
| `lockup-` | Bird plus wordmark. The canonical form of the brand. The `modular` variants redistribute the elements for extreme widths. |
| `hopechannel-` | The parent brand's endorsement. Required on all official material. |

## Background rule

Use a `-white` file on a dark background or photography. Use a `-black` file on a light
background. The `-dark-bg` and `-light-bg` files already carry the correct ink combination
for that ground — use them instead of recoloring.

## Inks

The bird's body is `black` `#28272A`; the defining wing is `fire-orange` `#FE5442`; the
`-white` variants invert the body to `white` `#FFFFFF` and keep the wing orange.

## Never

Distort, stretch or rotate. Recolor outside the variants here. Separate the icon from the
wordmark in a combined lockup. Apply a shadow, outline or gradient. Minimum clearspace is
the height of the "T" in the wordmark.
