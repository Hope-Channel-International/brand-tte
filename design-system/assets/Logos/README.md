# Logos

Vinte e seis SVGs: o mark (pássaro), o wordmark, o lockup completo e a co-marca
Hope Channel. Todos vetoriais, nas cores aprovadas — nenhum usa `currentColor`.

## Como escolher

| Prefixo | Quando usar |
|---|---|
| `mark-` | O símbolo sozinho. Avatar, favicon, aplicação pequena, ou quando o wordmark já aparece no contexto. |
| `wordmark-` | Só a tipografia. As variantes `orange` trazem "THE EARTH" em `fire-orange` — a forma preferida quando há espaço. |
| `lockup-` | Pássaro + wordmark. A forma canônica da marca. As variantes `modular` distribuem os elementos para larguras extremas. |
| `hopechannel-` | Endosso da marca-mãe. Obrigatório em todo material oficial. |

## Regra de fundo

Arquivo `-white` sobre fundo escuro ou fotografia. Arquivo `-black` sobre fundo claro.
Os arquivos `-dark-bg` e `-light-bg` já vêm com a combinação de tintas correta para
aquele fundo — use-os em vez de recolorir.

## Tintas

O corpo do pássaro é `black` `#28272A`; a asa definidora é `fire-orange` `#FE5442`;
as variantes `-white` invertem o corpo para `white` `#FFFFFF` e mantêm a asa laranja.

## Nunca

Distorcer, esticar ou rotacionar. Recolorir fora das variantes aqui. Separar o ícone
do wordmark num lockup combinado. Aplicar sombra, contorno ou gradiente.
Clearspace mínimo é a altura do "T" do wordmark.
